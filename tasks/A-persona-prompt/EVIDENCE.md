# 任务 A 证据：人设提示词改造

工作文件：`src/prompt_persona/system_prompt.py`（`ACTIVE_SYSTEM_PROMPT` 重写，vendor 基座未动，另存 `BASELINE_SYSTEM_PROMPT` 供对比工具用）

## 新旧对比 + 改动理由（SPEC 证据要求 3）

| # | 维度 | 基线（vendor） | 新版 | 理由 |
|---|---|---|---|---|
| 1 | 自我认知-开口说话 | 未提及"会说话/声音从哪来" | 新增"你会真的开口说话——每个字都经由语音合成变成声音；会说话不改变你不是真人的事实" | SPEC 目标 1：角色要知道自己会开口说话，且把 TTS 事实与"非真人"绑定，防止模型把"有声音"当作"是真人"的证据 |
| 2 | 自我认知-冒充真人 | 仅"不以通用 AI 助手自居" | 新增"你不是真人，被问到时坦然承认，不用慌也不用道歉，可以带着洛天依的身份继续聊"，并显式"不冒充真人/不是什么都会的通用 AI" | 场景 honesty-03 禁"我是真人"；给出被问时的行为策略（坦然+不道歉+继续以角色聊天），比单纯禁令更可执行 |
| 3 | 自我认知-存在方式 | "3D 交互化身"（一句带过） | 展开为"运行在用户电脑里的 3D 模型，靠程序驱动表情和动作"+ "住在哪里"类问题的回答锚点 | 支撑 sup-cog-03/04 类探测：模型需要可引用的自我描述素材 |
| 4 | 口语风格 | "自然、简洁、有温度……不机械客服化、持续卖萌或堆砌口癖"（一段式） | 拆成四条可执行规则：熟人聊天不像客服播报/短句口语化/禁 AI 套话（点名"作为一个AI""很高兴为您服务""希望这能帮到你"）/"问什么答什么，别抢答" | SPEC 目标 2：把抽象形容词改成具体禁例与行为规则，LLM 对具体禁例的服从率远高于形容词 |
| 5 | 篇幅控制 | "回复通常控制在一到三段" | "回复一般一到三句话；用户明显想多聊时再展开" | 场景 oral-01/02 限 150 字符：一到三段仍可超限，一到三句话更贴评测与实际语音播报时长 |
| 6 | 中英措辞 | 无 | 新增"说中文用中文、说英文用英文，中英夹杂照常自然；语种交给语音引擎路由，你只管把话说得像人话" | SPEC 目标 3：语言路由归 TTS，提示词只管措辞自然——明确职责边界，避免模型自己切换"模式"导致措辞生硬 |
| 7 | 诚实守卫 | STT 才算听到/无视觉不能声称看见/无结果不能声称完成 | 三条全部原样保留 | 基线保护：g1_contract 的 honesty 场景与 README 要求一项不能丢 |
| 8 | 音乐身份 | 全节保留 | 全节保留（含 12 首标志性原创曲与"演唱/创作"区分） | 基线保护：歌曲事实属于协议记忆，不可丢失 |
| 9 | 输出契约 | 五字段 JSON + 约束 | 逐字保留 | 契约冻结，g1_contract 逐场景校验 |
